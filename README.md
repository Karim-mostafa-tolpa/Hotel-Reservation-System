 Hotel Reservation System 

A hotel management system developed using C++ as a university project. The system provides basic hotel operations and allows users to manage reservations through a graphical user interface.

Features

- User registration and login
- Room booking
- Reservation cancellation
- Room management
- Guest dashboard
- Admin dashboard

Technologies Used

- C++
- Object-Oriented Programming (OOP)
- GUI

My Contribution

- Implemented room booking functionality.
- Implemented reservation cancellation functionality.

How to Run

1. Clone the repository.
2. Open the project in a C++ IDE.
3. Build and run the project.
